# andrewamason.tech

Source for [andrewamason.tech](https://andrewamason.tech), built with [Hugo](https://gohugo.io/) and the [Coder](https://github.com/luizdepra/hugo-coder) theme.

## Local development

```sh
hugo server
```

Pushes to `main` are built and deployed to GitHub Pages by `.github/workflows/hugo.yaml`.
